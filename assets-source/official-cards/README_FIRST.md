# Albastini Temporary Individual Card Pack

This pack contains:
- 8 reconstructed individual card fronts
- 1 reconstructed card back
- genuine real-source card photographs for reference

The project owner has explicitly approved using the reconstructed individual cards
temporarily on the Albastini website until official straight-on scans are obtained.

Keep them marked `temporary_reference` / `ai_reconstructed_reference`.
Do not label them official. They should be easy to replace later.
